# Scroll behaviour · the documentation site

Everything that moves, appears or changes as a page of the site scrolls, in the order a
reader meets it. Values are taken from the code: `src/components/shell/RulerScrollbar/ruler.ts`,
`src/shared/lib/glide.ts`, `src/shared/lib/useHere.ts`, `src/components/shell/Reveal/`,
`src/components/docs/Sheet/` and `src/features/landing/proof/assembly/`. The TDD
(`TDD-ui-platform-docs-001-documentation-site.md`, D13 to D19) holds the decisions; this
file holds the behaviour and its numbers.

> **Status.** Since 2026-10-27 this file is the source of the site's scroll behaviour.
> It began as `scnx-platform/SCROLL.md` in `anshacerbia2/scnehaux-design` (the Square
> reference, ADR-UIP-VIS-002), which is kept there as history and no longer follows
> the site. The values are expression-local guidance (ADR-UIP-VIS-002): the 28px reveal
> goes past Instrument's 4px rise, and the set needs an ADR-UIP-VIS-001 revision before
> it becomes a rule. Numbering follows the reference's, so code that cites a section
> (for example "SCROLL.md 6.9") still points at the same behaviour.

Terms used below:

| Term            | Meaning                                                                                                                                                                                                      |
| :-------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _section line_  | The 1px rule at the top of a section (`main [data-sheet]`), as it sits on screen.                                                                                                                            |
| _nav_           | The 48px navigation strip, held at the top of the viewport. Its own line is its last row (47px).                                                                                                             |
| _p_             | Page progress, `scrollY / maxScroll × 100` (0–100).                                                                                                                                                          |
| _rest / folded_ | The ruler at page scale / the ruler folded into 0–100 (hover, focus or drag).                                                                                                                                |
| _half a pixel_  | A threshold, not rounding. Section tops are often fractional (48.4px), so a line within half a pixel of a mark counts as having reached it. Every position is still computed and drawn unrounded (to 0.1px). |

## 1. Page load

| #   | Behaviour            | Detail                                                                                                                                                                                                                                                                           |
| :-- | :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.1 | Page held hidden     | The server sends `html.sq-boot`; everything below the nav stays hidden until `Reveal` has marked the blocks, in the same task, before first paint, and sets `data-sq-booted`. A 2.5s failsafe shows the page in any case, without JavaScript too. Reduced motion never hides it. |
| 1.2 | Reveal, first screen | Blocks already in view rise at once (see 3.1), 80ms apart in document order.                                                                                                                                                                                                     |
| 1.3 | Rules draw           | Each section's rule draws in from the left once it is in view (see 2.2).                                                                                                                                                                                                         |
| 1.4 | Ruler appears        | At 1024px and wider. The native scrollbar is hidden (`html[data-ruler="on"]`) and the 60px ruler takes its place. The titles are placed for the current scroll position with no flight.                                                                                          |
| 1.5 | Measure              | Section positions, the page height, the free margin and title widths are measured once, then again on resize, on a body resize, when fonts load, and after each reveal wave (a block still lowered by 28px lengthens the page; `Reveal` sends `sq:layout`).                      |

## 2. Lines and section bars

| #    | Behaviour             | Detail                                                                                                                                                                                                                                                                                                                                            |
| :--- | :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2.1  | Nav                   | Sticky at the top, 48px, above everything (z 50), including the ruler. A strip of cells with one line between any two. At 1320px and below the sheet readout leaves (the ruler repeats it; the strip needs 1314px with it), at 1180px the GitHub cell, at 1080px the Get started link (the call to action repeats it), and below 980px the links. |
| 2.2  | Section rule draws in | 1px, the width of the viewport, scaled 0 → 1 from the left over 1100ms. It runs once, when 12% of the section shows above the bottom 18% of the viewport (`Reveal` sets `data-drawn`). On a reference page (`DocsLayout`) the rule spans the page column only.                                                                                    |
| 2.3  | Crosses               | An 11px cross in a strong line sits where each rule meets a column line. Static.                                                                                                                                                                                                                                                                  |
| 2.3a | First section         | On a page of sheets, no rule and no crosses: it starts right under the nav, whose own line is its top line.                                                                                                                                                                                                                                       |
| 2.4  | Section bar holds     | `NN / Name ··· facts` is sticky under the nav (`top: 48px`) while its section is in view, on glass: the ground at 72%, blurred 12px, so the page reads through it (the owner, 2026-10-27).                                                                                                                                                        |
| 2.5  | Bar top line          | The rule sits above the bar (z 31 over z 30), so it is the bar's top line until the bar sticks. By then the rule has scrolled under the nav, and the nav's bottom line takes over. One line, never two.                                                                                                                                           |
| 2.6  | Bar pushed out        | The next section pushes a held bar up. The bar's −1px bottom margin lands its line on the next rule, so they don't sit 1px apart.                                                                                                                                                                                                                 |
| 2.7  | "Here" on the bar     | The bar's number turns blue when its section is current: when its line reaches the nav (see 6.9). The nav's `Sheet NN/07 NN%` readout and a reference page's "On this page" switch at the same moment, as do the ruler's titles, readout and ledger.                                                                                              |

## 3. Content

| #   | Behaviour         | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| :-- | :---------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3.1 | Reveal on entry   | A block rises from 28px below and an 8px blur to rest: opacity, translate and blur over 900ms, `power3.out`. It runs once, when 12% of the block is visible (the bottom 6% of the viewport excluded). Blocks entering together are staggered 80ms apart in document order, capped at 8 steps.                                                                                                                                                                                                                                                                                                                                                                                  |
| 3.2 | What rises        | The finest blocks: the page head's parts and each block of a sheet's body (`main > header > *`, `main [data-sheet-body] > *`); a block that holds another gives way to it. Sticky elements never rise.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 3.3 | The assembly      | The landing's exploded view (TDD D19) is drawn with WebGL. Its plates fall into place once on first show (1100ms, the last one last), then close as the reader scrolls: from where the stage's centre passes 50% of the viewport, over 22% of the viewport, so they are apart on arrival and closed well before the figure leaves. Apart and Assembled set an offset from where the scroll puts the stack, which scrolling wears away as fast as it moves the stack; every change, scrolled or pressed, is eased with a 180ms time constant. The "Assembly NN%" readout follows. Under reduced motion the stack stays apart while scrolling, and the controls move it at once. |
| 3.4 | Clean-up          | The reveal attributes are removed once a block is at rest (1100ms plus its delay), so nothing lingers on the element.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 3.5 | Not scroll-driven | The receipt tape runs on its own (an 80s loop) and pauses on hover and focus. The hero's check draws in once, 700ms after load. The lineage on `/get-started` traces its four contracts 600ms after half of it comes into view, and again whenever another component is picked.                                                                                                                                                                                                                                                                                                                                                                                                |

## 4. Smooth scroll

| #   | Behaviour           | Detail                                                                                                                                                                                                                    |
| :-- | :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 4.1 | Wheel glides        | Every wheel input, mouse or trackpad, moves a target. The page eases toward it with a 120ms time constant and lands within 0.5px. Inputs add up while gliding.                                                            |
| 4.2 | Trackpad            | It glides like the mouse. Its many small deltas add up to one eased movement.                                                                                                                                             |
| 4.3 | Left to the browser | Ctrl or pinch zoom, a mostly horizontal swipe, an element under the pointer that can still scroll that way (a reference page's sidebar, code blocks), an event another handler has already taken, and reduced motion.     |
| 4.4 | Others take over    | Keys, anchor links, find-in-page, a route change and the native scrollbar on narrow screens move the page directly. A glide in progress yields to them. The ruler's own title links are the exception: they glide (6.12). |
| 4.5 | Line units          | `deltaMode` 1 counts 16px per line; `deltaMode` 2 counts one viewport per page.                                                                                                                                           |
| 4.6 | Same frame          | The ruler and titles are redrawn in the frame the glide moves the page, never a frame behind (`onGlideWrite`).                                                                                                            |

## 5. The ruler at rest

| #   | Behaviour      | Detail                                                                                                                                                                                                                        |
| :-- | :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5.1 | Page scale     | One tick per 1% of the page (10px), with a 20px tick and its number every 5. The tick for value _v_ sits at `nowY + (v − p) × pageHeight / 100`. The whole scale moves as one transform.                                      |
| 5.2 | Now line       | A blue line at `nowY = 60 + p × (viewport − 74) / 100`, sliding down the viewport as the page scrolls.                                                                                                                        |
| 5.3 | Readout        | Under the now line, like a receipt: `05 · 042%` (the current section, then _p_).                                                                                                                                              |
| 5.4 | The ledger     | A 20×2px mark at each section's place in the document (`top / pageHeight`). Marks are faint ahead, ink for the current section, and blue with a drawn check once read (an earlier section, or every section once _p_ ≥ 99.5). |
| 5.5 | Nothing behind | No glass, plate or halo behind the ruler or its titles (the owner, 2026-10-26; the blurred glass and the plates tried after it read badly).                                                                                   |

## 6. Section titles

Every letter is placed from the scroll position, so scrolling back plays everything
back. Each title moves letter by letter, the last letter first. 55% of a move is
spent staggering the letters, eased in and out (cubic).

| #   | Place         | Position and look                                                                                                                                                                                                                                                                                                                                                                                                  |
| :-- | :------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 6.1 | Stack (ahead) | Small (16px at the largest size; 16/34 of the large size), right-aligned at the ruler, bottom-aligned: `y = viewport − 37 − (last − i) × row`. A **row** of either stack is the small size plus a quarter (20px at the largest, about 13px at 1024px). Tone 68% (4.5:1 or more in both modes).                                                                                                                     |
| 6.2 | Standing      | Upright on the ruler (rotated −90°, 18px). It hangs from its section line (top at line + 8px). Its foot never goes lower than 8px above the next title waiting in the stack, and its top never higher than 8px under its own current place, so it never covers either stack: near the top it stops there while its line goes on to the nav, and lies down from that place. Tone 68% (4.5:1 or more in both modes). |
| 6.3 | Current       | Large: `clamp(1.77% of viewport width, 22, 34)px`, shrunk toward the free margin (never below 80%). `y = 66 + i × row + size`. Full tone, with a blue check beside it once whole.                                                                                                                                                                                                                                  |
| 6.4 | Read stack    | Small, top-aligned under the nav: `y = 66 + 0.45 × row + i × row` (75 + i × 20 at the largest). Tone 68% (4.5:1 or more in both modes).                                                                                                                                                                                                                                                                            |

| #    | Move                 | Trigger (section line on screen)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :--- | :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 6.5  | Stack ↔ standing     | Measured from the bottom stack, right at it. Scrolling up, the standing title rides down with its line until its foot is 8px above the next title waiting in the stack; it stops there, and lies into its place while its line runs on down its own standing length, to that same edge. Scrolling down, the reverse: it stands up there as its line rises from the edge, and rides with the line once the line has risen clear. So the move takes as long as the title is tall, and never crosses the stack. Where the viewport leaves no room for it before 6.7, the title goes from the stack to the current place directly.                                                                   |
| 6.6  | Standing rides       | The title moves with its line.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 6.7  | Standing → current   | Starts when the line is 140px below the current title's place, and is complete when the line reaches the nav (within half a pixel); the standing title stops 8px under that place (6.2) and lies down from there. Where the page ends first, it completes at the highest point the line can reach. It never starts until the previous section's line is 24px past the nav, so a short section makes the next title lie down over a shorter stretch, never early.                                                                                                                                                                                                                                 |
| 6.8  | Current → read stack | Driven by the next section's line over the same stretch as 6.7, but done within its first 45% (1 − the 55% letter stagger): the current place is empty before the next title's first letter lands there.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 6.9  | Current section      | The last one whose line has reached the nav (within half a pixel). Where the page ends first, the highest point its line can reach counts instead. This is the moment its section bar is held. It is the page's one "here": the ruler (titles, readout, ledger, check), the bar's blue number, the nav's readout and a reference page's contents all switch on it. `HereProvider` and the ruler run the same `currentSection` (`useHere.ts`).                                                                                                                                                                                                                                                    |
| 6.10 | Check                | Drawn beside the current title, centred on its capitals (not on the line box, which also holds the room below the baseline), once it is whole: not moving in or out, and not being verified. Because of 6.7, that is always true at the moment the line reaches the nav (or the end of the page), so the title is level and checked at that moment, never after. The check draws in over 420ms. Hidden while the ruler is folded.                                                                                                                                                                                                                                                                |
| 6.11 | Verified on demand   | Hovering or focusing a title at rest shows its letters as hash characters (`0–9 A–F`, changing every 50ms) for 120ms, then resolves them left to right, one every 45ms. The check is drawn again after, when the title is the current one. "At rest" covers the current title, both stacks, and every title while the ruler is open or opening. A title in a scroll move, or with the ruler closing, is not at rest. Standing titles sit on the ruler, so pointing at one opens the ruler first. Once per entry; not under reduced motion. Nav links and calls to action use the same shuffle (`Shuffle`).                                                                                       |
| 6.12 | Links                | Each title is a link to its section, covering the title where it mostly is; in a stack the link is one row tall, so two links never overlap and a click reaches the title under the pointer. A click glides like a wheel (a modified click is left to the browser). A jump, from a title, the contents or a `#hash`, lands the section's line on the nav's own line, its last row (47px, `JUMP_LINE`; the document's `scroll-padding-top`): one line, never a double border. The first sheet of a page of sheets has no rule (2.3a), takes 1px of scroll-margin and lands at the top of the page, exactly where it loads. The ruler reads each sheet's scroll-margin, so every jump lands alike. |

**The same at every width.** Wherever the ruler shows (1024px and up), the titles keep
one layout and one behaviour:

- Read stack, large current title with its check, standing next title, and the waiting stack.
- Only the size follows the viewport: 1.77% of its width, between 22 and 34px.
- The large title shrinks toward the free margin between the column and the ruler, but never below 80%.
- Where the margin is narrower, the titles overlap the page's top-right corner, with nothing behind them (5.5).

## 7. The ruler folded

| #   | Behaviour    | Detail                                                                                                                                                              |
| :-- | :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 7.1 | Fold         | Pointer over the ruler, focus on it, or a drag. Also kept while the pointer moves onto a title link. It eases with a 170ms time constant.                           |
| 7.2 | Scale        | 0–100 over the viewport, from 60px to `viewport − 14px`.                                                                                                            |
| 7.3 | Window       | A shaded box marks the part of the page in view (`scrollY` to `scrollY + viewport`, as fractions of the page).                                                      |
| 7.4 | Cursor       | A 3px ink line at the pointer.                                                                                                                                      |
| 7.5 | Titles       | All small and level, each at its section's place on the scale. Current at full tone, the rest at 86%. They move in letter by letter over the first 40% of the fold. |
| 7.6 | Click        | Glides to the point under the pointer: `(y − 60) / (viewport − 74)` of the page.                                                                                    |
| 7.7 | Drag         | Glides after the pointer, closer behind than a wheel (80ms time constant), and lands where the pointer is on release.                                               |
| 7.8 | Onto a title | Moving the pointer from the ruler onto a title keeps the ruler open, so its titles can be read, verified (6.11) or followed.                                        |
| 7.9 | Unfold       | When the pointer leaves both the ruler and its titles, unless dragging or focused.                                                                                  |

## 8. Keyboard

The ruler is focusable (`role="scrollbar"`, Tab), and folds on focus.

| Key        | Moves to                                                                                 |
| :--------- | :--------------------------------------------------------------------------------------- |
| ↓ / →      | +1% (Shift: +5%)                                                                         |
| ↑ / ←      | −1% (Shift: −5%)                                                                         |
| Page Down  | The next section's line on the nav's line (where a jump lands, 6.12)                     |
| Page Up    | The current section's line on the nav's line, or the previous section's if already there |
| Home / End | Top / bottom                                                                             |

Moves glide like a wheel notch. It announces `aria-valuenow` and `aria-valuetext`, such as "42%, Guarantees". The keyboard keeps its native page scrolling everywhere else.

## 9. Where it is off

| Condition      | What changes                                                                                                                                                                                                                                     |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reduced motion | No glide, no reveal, no rule drawing, no hash shuffle, no turntable. The fold opens at once, with no letter stagger. Titles still follow the scroll, because they are positions, not timed animations. The assembly stays apart while scrolling. |
| Below 1024px   | No ruler, no titles. The native scrollbar returns. Reveal and wheel glide stay. The column takes the full width, without its side lines and the crosses on them (the owner, 2026-10-27).                                                         |
| No WebGL       | The assembly is its text: the four contracts as a list, and its caption.                                                                                                                                                                         |
| No JS          | The finished page with the native scrollbar, shown by the 2.5s failsafe.                                                                                                                                                                         |

## One "here"

The site has one definition of the current section: its line has reached the nav
(6.9). `HereProvider` decides it for the bars, the nav readout and the contents; the
ruler runs the same `currentSection` in the frame it draws.

## Performance

- **No layout reads while scrolling.** Section positions are measured on resize and cached. A style is written only when it changes.
- **One loop for the ruler.** It runs only while the fold animates or a hover-verify runs. A glide redraws the ruler from inside its own frame.
- **The assembly draws on demand.** Its scene loads in its own chunk when the hero mounts, renders only when something changed and while the figure is in view, and reads the palette again only when a theme root around it changes mode.
